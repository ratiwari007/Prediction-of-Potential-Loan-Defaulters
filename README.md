# Prediction-of-Potential-Loan-Defaulters
To identify the customers segments that are eligible for loan amount so that they can specifically target these customers
Automate the loan eligibility process (real time) based on customer detail provided while filling online application form. These details are Gender, Marital Status, Education, Number of Dependents, Income, Loan Amount, Credit History and others. To automate this process, Client has provided a dataset to identify the customers segments that are eligible for loan amount so that they can specifically target these customers.
